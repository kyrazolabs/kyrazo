# Encryptions

`backend/shared/src/utils/libs/crypto/encryptions`

This folder holds the encryptions code for the shared backend library.

## Contents

### Files

- `hash.crypto.ts` — exports `HasherCrypto`, `hasherCrypto`
- `key.crypto.ts` — exports `KeyCrypto`
- `secret.crypto.ts` — exports `SecretCrypto`
- `signature.crypto.ts` — exports `SignatureCrypto`, `signatureCrypto`
