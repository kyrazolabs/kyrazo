# Configs

`backend/shared/src/configs`

This folder holds startup configuration for the shared backend library.

## Contents

### Files

- `app.ts` — exports `config`
- `clickhouse.ts` — exports `ClickHouseConfig`
- `index.ts`
- `logger.ts` — exports `log`, `loggerStream`, `logger`
- `mongo.ts` — exports `DatabaseConfig`
