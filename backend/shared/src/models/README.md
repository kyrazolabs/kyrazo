# Models

`backend/shared/src/models`

This folder holds data shapes for the shared backend library.

## Contents

### Folders

- [clickhouse](clickhouse/README.md) — ClickHouse tables, migrations, and queries for event history
- [mongodb](mongodb/README.md) — Mongoose models for users, workspaces, endpoints, and the rest of the transactional data
