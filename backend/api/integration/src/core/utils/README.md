# Utils

`backend/api/integration/src/core/utils`

This folder holds small helpers for the integration API.

## Contents

### Folders

- [libs](libs/README.md) — low-level helpers and third-party wrappers

### Files

- `helpers.ts` — exports `generateIngressId`, `base62Encode`, `base62Decode`, `safeEncode` and 1 more
- `index.ts`
- `performance.ts` — exports `PerformanceTimer`, `measureAsync`, `measure`, `timed` and 1 more
- `source.ts` — exports `decryptSourceSecrets`, `mapToObject`
