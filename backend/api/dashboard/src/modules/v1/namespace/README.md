# Namespace

`backend/api/dashboard/src/modules/v1/namespace`

This folder holds namespaces, the routing boundary a customer's events belong to for the dashboard API.

## Contents

### Files

- `namespace.controller.ts` — exports `NamespaceController`
- `namespace.ratelimiter.ts` — exports `namespaceReadRateLimiter`, `namespaceWriteRateLimiter`
- `namespace.routes.ts`
- `namespace.schema.ts` — exports `CreateNamespaceSchema`, `UpdateNamespaceSchema`, `GetNamespaceByIdSchema`, `FilterNamespaceSchema` and 4 more
