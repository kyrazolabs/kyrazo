# Emails

`backend/api/dashboard/src/templates/emails`

This folder holds HTML email templates for the dashboard API.

## Contents

### Files

- `email-verification.html` — template, heading “Verify Your Email Address”
- `index.ts` — exports `EmailTemplateData`, `loadEmailTemplate`, `EMAIL_TEMPLATES`, `EmailTemplateType` and 4 more
- `password-reset.html` — template, heading “Reset Your Password”
- `welcome.html` — template, heading “Welcome aboard, {{firstName}}! 🎉”
- `workspace-invitation.html` — template
