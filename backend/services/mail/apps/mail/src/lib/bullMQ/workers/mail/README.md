# Mail

`backend/services/mail/apps/mail/src/lib/bullMQ/workers/mail`

This folder holds mail jobs for MailQ, the outbound mail service.

## Contents

### Folders

- [high](high/README.md) — the high-priority mail worker
- [low](low/README.md) — the low-priority mail worker
- [medium](medium/README.md) — the medium-priority mail worker
- [send](send/README.md) — the worker that sends a message
