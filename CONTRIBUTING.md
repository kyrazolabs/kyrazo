# Contributing to Kyrazo

This repository is the private property of Kyrazo LLC. It is not an open source project, and it does not accept unsolicited contributions.

## Permission comes first

Do not use, copy, fork, or change this repository, and do not open an issue or a pull request, unless Kyrazo LLC has given you written permission. That rule covers commercial work and non-commercial work. The terms are in [LICENSE](LICENSE).

If you do not have that permission, stop here. A pull request does not create permission, and it does not give you a license to use the software.

Permission requests go to [legal@kyrazo.com](mailto:legal@kyrazo.com).

## If you have written permission

- Branch from `develop`. Open the pull request against `develop`.
- Keep the change limited to what Kyrazo LLC asked you to do.
- Do not commit secrets, credentials, customer data, or local environment files.
- Follow the style already used in the directory you are editing. `backend/`, `dashboard/`, `website/`, `docs/`, and `sdks/` each have their own layout.
- Describe what changed and how you checked it.

Sending a contribution does not transfer any right in the software to you. You receive no license to use, copy, or redistribute Kyrazo's materials except what the written permission already grants. Kyrazo LLC may reject any submission.

## Security

Report a security problem to [legal@kyrazo.com](mailto:legal@kyrazo.com). Do not describe it in a pull request or an issue.
