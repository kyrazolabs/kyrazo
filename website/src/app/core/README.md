# Core

`website/src/app/core`

This folder holds cross-cutting code used by the rest of this package for the marketing site.

## Contents

### Folders

- [3rd-party](3rd-party/README.md) — browser integrations such as analytics and error reporting
- [models](models/README.md) — data shapes
- [resolvers](resolvers/README.md) — route resolvers that load data before a screen opens
- [seo](seo/README.md) — page titles, descriptions, and structured data
- [services](services/README.md) — business logic and API clients
