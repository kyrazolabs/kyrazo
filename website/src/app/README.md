# App

`website/src/app`

This folder holds the application source for the marketing site.

## Contents

### Folders

- [components](components/README.md) — UI components
- [core](core/README.md) — cross-cutting code used by the rest of this package
- [models](models/README.md) — data shapes
- [pages](pages/README.md) — routable screens
- [shared](shared/README.md) — code shared by the features next to it

### Files

- `app.config.server.ts` — exports `config`
- `app.config.ts` — exports `appConfig`
- `app.html` — template
- `app.routes.server.ts` — exports `serverRoutes`
- `app.routes.ts` — exports `routes`
- `app.scss`
- `app.spec.ts`
- `app.ts` — exports `App`
- `theme.config.ts` — exports `getNoirSemantic`, `getNoirPreset`, `getPrimarySemantic`, `getPrimaryPreset` and 2 more
