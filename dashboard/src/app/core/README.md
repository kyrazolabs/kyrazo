# Core

`dashboard/src/app/core`

This folder holds cross-cutting code used by the rest of this package for the Angular dashboard.

## Contents

### Folders

- [3rd-party](3rd-party/README.md) — browser integrations such as analytics and error reporting
- [auth](auth/README.md) — sign-in, registration, and session handling
- [guards](guards/README.md) — route guards that decide who can open a screen
- [interceptors](interceptors/README.md) — HTTP interceptors that attach auth and handle errors on every request
- [resolver](resolver/README.md) — route resolvers that load data before a screen opens
- [services](services/README.md) — business logic and API clients
