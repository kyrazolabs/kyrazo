# Resolver

`dashboard/src/app/core/resolver`

This folder holds route resolvers that load data before a screen opens for the Angular dashboard.

## Contents

### Files

- `dashboard.resolver.ts`
- `delivery.resolver.ts` — exports `deliveryResolver`, `deliveriesResolver`, `eventResolver`, `ingestLogsResolver`
- `endpoints.resolver.ts` — exports `endpointsResolver`, `endpointResolver`
- `keys.resolver.ts` — exports `keysResolver`, `keyResolver`
- `settings.resolver.ts` — exports `profileResolver`, `preferencesResolver`, `subscriptionResolver`, `plansResolver`
- `source.resolver.ts` — exports `sourcesResolver`, `ingestsResolver`, `sourceResolver`, `SourceDeliveriesResolver`
- `target.resolver.ts` — exports `targetResolver`, `targetsResolver`
