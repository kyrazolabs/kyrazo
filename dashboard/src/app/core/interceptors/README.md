# Interceptors

`dashboard/src/app/core/interceptors`

This folder holds HTTP interceptors that attach auth and handle errors on every request for the Angular dashboard.

## Contents

### Files

- `auth.interceptor.ts` — exports `authInterceptor`
- `error.interceptor.ts`
- `namespace.interceptor.ts` — exports `namespaceInterceptor`
- `retry.interceptor.ts` — exports `retryInterceptor`
- `workspace.interceptor.ts` — exports `workspaceInterceptor`
