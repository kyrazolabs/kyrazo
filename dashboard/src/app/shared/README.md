# Shared

`dashboard/src/app/shared`

This folder holds code shared by the features next to it for the Angular dashboard.

## Contents

### Folders

- [animations](animations/README.md) — UI animations
- [components](components/README.md) — UI components
- [directives](directives/README.md) — Angular directives
- [module](module/README.md) — the Angular module that declares the pieces in this area
- [services](services/README.md) — business logic and API clients
- [ui](ui/README.md) — small shared UI pieces
