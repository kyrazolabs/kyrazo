# Components

`dashboard/src/app/shared/components`

This folder holds UI components for the Angular dashboard.

## Contents

### Folders

- [avatar-selection-dialog](avatar-selection-dialog/README.md) — the avatar picker
- [code-editor](code-editor/README.md) — the code editor used for transforms
- [copy-id](copy-id/README.md) — the control that copies a record id
- [invite-member-form](invite-member-form/README.md) — the form for inviting a workspace member
- [namespace-form](namespace-form/README.md) — the form for creating and editing a namespace
- [otp-dialog](otp-dialog/README.md) — the one-time-password dialog
- [support-dialog](support-dialog/README.md) — the support contact dialog
- [twofa-setup-dialog](twofa-setup-dialog/README.md) — the two-factor setup dialog
