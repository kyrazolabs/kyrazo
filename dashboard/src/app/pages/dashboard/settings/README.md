# Settings

`dashboard/src/app/pages/dashboard/settings`

This folder holds workspace and account settings for the Angular dashboard.

## Contents

### Folders

- [billing](billing/README.md) — plans, subscriptions, and payments
- [notification](notification/README.md) — the notification screen
- [profile](profile/README.md) — the signed-in user's profile
- [workspace](workspace/README.md) — workspaces, the tenant boundary

### Files

- `settings.page.html` — template, heading “Profile Settings”
- `settings.page.scss`
- `settings.page.spec.ts`
- `settings.page.ts` — exports `SettingsPage`
- `settings.routes.ts` — exports `settingsRoutes`
