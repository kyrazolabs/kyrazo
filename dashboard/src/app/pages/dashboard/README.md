# Dashboard

This folder is the dashboard screen in the Angular dashboard.

### Folders

- [app-shell](app-shell/README.md) — the signed-in application shell
- [billing](billing/README.md) — plans, subscriptions, and payments
- [connectors](connectors/README.md) — the connector catalog
- [deliveries](deliveries/README.md) — the delivery history screen
- [events](events/README.md) — event message types and publishers
- [inspector](inspector/README.md) — the event inspector
- [invitation](invitation/README.md) — workspace invitations
- [namespaces](namespaces/README.md) — namespaces, the routing boundary a customer's events belong to
- [secrets](secrets/README.md) — signing secrets
- [settings](settings/README.md) — workspace and account settings
