# Components

`dashboard/src/app/components`

This folder holds UI components for the Angular dashboard.

## Contents

### Folders

- [dashboard](dashboard/README.md) — the dashboard code
- [footer](footer/README.md) — the page footer
- [json-viewer](json-viewer/README.md) — the JSON viewer
- [launchpad](launchpad/README.md) — the screen that asks a new account to pick a workspace and a namespace
- [service](service/README.md) — the business logic
- [sidebar](sidebar/README.md) — the dashboard sidebar
- [topbar](topbar/README.md) — the dashboard top bar
- [worker](worker/README.md) — worker registration and status

### Files

- `app.config.ts` — exports `AppConfig`
- `app.footer.ts` — exports `AppFooter`
- `app.topbar.ts`
