## This folder

This folder holds the dashboard top bar for the Angular dashboard.

- Branch from `develop` and open the pull request against `develop`.
- Keep the diff inside `dashboard/src/app/components/topbar` unless the change cannot work without a neighboring folder.
- Match the style of the files already in this folder.
- Do not commit secrets, credentials, or `.env` files.

## Checks

This folder has no script of its own. From `dashboard`:

```bash
bun run test
bun run build
```
