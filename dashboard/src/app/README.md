# App

`dashboard/src/app`

This folder holds the application source for the Angular dashboard.

## Contents

### Folders

- [components](components/README.md) — UI components
- [core](core/README.md) — cross-cutting code used by the rest of this package
- [models](models/README.md) — data shapes
- [pages](pages/README.md) — routable screens
- [shared](shared/README.md) — code shared by the features next to it

### Files

- `app.component.html` — template
- `app.component.scss`
- `app.component.spec.ts`
- `app.component.ts` — exports `AppComponent`
- `app.config.ts` — exports `appConfig`
- `app.routes.ts` — exports `routes`
