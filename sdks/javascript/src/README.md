# Source

`sdks/javascript/src`

This folder holds the source files for the JavaScript SDK.

## Contents

### Folders

- [modules](modules/README.md) — feature modules
- [types](types/README.md) — shared types
- [utils](utils/README.md) — small helpers

### Files

- `client.ts` — exports `Kyrazo`
- `config.ts` — exports `KyrazoConfig`, `DEFAULT_CONFIG`, `resolveConfig`
- `errors.ts` — exports `ValidationErrorDetail`, `APIErrorResponse`, `KyrazoError`, `AuthenticationError` and 4 more
- `index.ts`
- `version.ts` — exports `VERSION`
- `webhook.ts` — exports `WebhookHeaders`, `Webhook`
