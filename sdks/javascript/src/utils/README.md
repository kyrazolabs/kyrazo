# Utils

`sdks/javascript/src/utils`

This folder holds small helpers for the JavaScript SDK.

## Contents

### Files

- `helpers.ts` — exports `sleep`, `generateIdempotencyKey`, `removeUndefined`, `deepMerge` and 2 more
- `http.ts` — exports `HttpMethod`, `HttpRequestConfig`, `HttpResponse`, `HttpClient`
- `validation.ts` — exports `validateString`, `validateUrl`, `validateArray`, `validateObject` and 3 more
