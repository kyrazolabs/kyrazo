## This folder

This folder holds delivery targets for the Python SDK.

- Branch from `develop` and open the pull request against `develop`.
- Keep the diff inside `sdks/python/kyrazo/resources/targets` unless the change cannot work without a neighboring folder.
- Match the style of the files already in this folder.
- Do not commit secrets, credentials, or `.env` files.
