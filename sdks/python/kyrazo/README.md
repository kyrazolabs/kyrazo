# Kyrazo

`sdks/python/kyrazo`

## Contents

### Folders

- [core](core/README.md) — cross-cutting code used by the rest of this package
- [models](models/README.md) — data shapes
- [resources](resources/README.md) — API resource clients

### Files

- `__init__.py`
- `client.py` — exports `Kyrazo`
- `webhook.py` — exports `Webhook`
