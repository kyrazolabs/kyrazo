# Resources

`sdks/python/tests/resources`

This folder holds API resource clients for the Python SDK.

## Contents

### Files

- `test_endpoints.py` — exports `test_create_endpoint_success`, `test_get_endpoint_secret`, `test_list_endpoints`
- `test_events.py` — exports `test_publish_event_success`, `test_publish_event_idempotency`, `test_publish_event_automatic_idempotency`
- `test_sources.py` — exports `test_create_source_success`, `test_list_sources`, `test_create_source_with_auth`
- `test_targets.py` — exports `test_create_target_success`, `test_delete_target`, `test_get_target_secret`, `test_update_target_status`
