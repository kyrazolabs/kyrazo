## Overview

The Integration API allows you to programmatically publish events and manage webhook targets within your namespaces. It is designed for high-performance and reliable event delivery.

## Authentication

All API endpoints are authenticated using the **x-api-key** header. Manage API keys in **your** Kyrazo dashboard (the hostname from your Order Form) under the **Secrets Page**.

```bash
x-api-key: <your_api_key>
```

### Idempotency

To prevent duplicate processing of the same request (e.g., due to network retries), you can provide an optional `X-Idempotency-Key` header. Kyrazo ensures that requests with the same key are processed only once.

```bash
X-Idempotency-Key: <unique_key>
```

## Base URL

There is no shared API host. Use the dedicated hostname from your Order Form (Kyrazo subdomain or your custom domain):

```http
https://{YOUR_HOST}
```

<Note>
  Publish URL: `https://{YOUR_HOST}/v1/events/{namespaceId}/publish`. Pass this host to the SDK as `baseURL` / `base_url`.
</Note>

### Usage Example

<CodeGroup>
```javascript Node.js
import {
  AuthenticationError,
  Kyrazo,
  LimitExceededError,
  RateLimitError,
  ValidationError,
} from "@kyrazo/sdk";

const client = new Kyrazo(process.env.KYRAZO_API_KEY, {
  baseURL: process.env.KYRAZO_BASE_URL, // https://{YOUR_HOST}
});

try {
  // Create a webhook target
  const target = await client.targets.create("ns_69674fad7590d01406e98126", {
    name: "Production Webhook",
    url: "https://api.example.com/webhooks",
    method: "POST",
    config: { timeout: 5000, retryCount: 3, rateLimitDuration: 60 },
  });

  // Publish an event
  await client.events.single("pro_696...", {
    event: "user.created",
    payload: {
      user_id: "u_334",
      email: "user@example.com",
      plan: "pro",
    },
    targets: [target.data.id],
  });
} catch (error) {
  if (error instanceof RateLimitError) {
    console.log(`Rate limited. Retry in ${error.retryAfter}s`);
  } else if (error instanceof LimitExceededError) {
    console.log("Deployment limit reached. Contact your Kyrazo account team.");
  } else if (error instanceof ValidationError) {
    console.log("Invalid payload:", error.message);
  } else if (error instanceof AuthenticationError) {
    console.log("Invalid API key");
  }
}
```
