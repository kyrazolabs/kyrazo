## Overview

The Integration API allows you to programmatically publish events and manage webhook targets within your projects. It is designed for high-performance and reliable event delivery.

## Authentication

All API endpoints are authenticated using the **x-api-key** header. You can manage your API keys within the [Kyrazo Dashboard](https://kyrazo.com/dashboard) under the **Secrets Page**.

```bash
x-api-key: <your_api_key>
```

### Idempotency

To prevent duplicate processing of the same request (e.g., due to network retries), you can provide an optional `X-Idempotency-Key` header. Kyrazo ensures that requests with the same key are processed only once.

```bash
X-Idempotency-Key: <unique_key>
```

## Base URL

The production base URL for the Kyrazo Integration API is:

```http
https://api.kyrazo.com
```

<Note>
  Ensure you are using the correct Project ID from your dashboard when constructing the publish URL: `https://api.kyrazo.com/v1/events/{projectId}/publish`
</Note>

### Usage Example

<CodeGroup>
```javascript JavaScript
import {
  AuthenticationError,
  Kyrazo,
  LimitExceededError,
  RateLimitError,
  ValidationError,
} from "@kyrazo/sdk";

const client = new Kyrazo({
  apiKey: "kz_live.v2.hSuq...",
});

try {
  // Create a webhook target
  const target = await client.targets.create("pro_69674fad7590d01406e98126", {
    name: "Production Webhook",
    url: "https://api.example.com/webhooks",
    method: "POST",
    config: { timeout: 5000, retryCount: 3, rateLimitDuration: 60 },
  });

  // Publish an event
  await client.events.single("pro_696...", {
    eventType: "user.created",
    payload: {
      user_id: "u_334",
      email: "user@example.com",
      plan: "pro",
    },
    targets: [{ targetId: target.data.id }],
  });
} catch (error) {
  if (error instanceof RateLimitError) {
    console.log(`Rate limited. Retry in ${error.retryAfter}s`);
  } else if (error instanceof LimitExceededError) {
    console.log("Monthly limit exceeded. Upgrade your plan.");
  } else if (error instanceof ValidationError) {
    console.log("Invalid payload:", error.message);
  } else if (error instanceof AuthenticationError) {
    console.log("Invalid API key");
  }
}
```
