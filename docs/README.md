# Docs

`docs`

Product documentation published with Mintlify. Guides live in essentials, and the HTTP reference lives in api-reference.

## Contents

### Folders

- [api-reference](api-reference/README.md) — reference pages for the integration API, one page per operation, plus the OpenAPI documents those pages are generated from
- [essentials](essentials/README.md) — concept guides: sources, endpoints, delivery, transforms, and the rest of the product model
- [images](images/README.md) — images
- [logo](logo/README.md) — logo files
- [sdks](sdks/README.md) — guides for the JavaScript, Python, and Go SDKs
- [snippets](snippets/README.md) — reusable documentation fragments

1 image files sit alongside the files below.

### Files

- `GEMINI.md` — Mintlify documentation
- `RULES.md` — Kyrazo Documentation Rules & Style Guide
- `docs.json` — Mintlify navigation and theme
- `index.mdx` — Introduction
- `quickstart.mdx` — Quickstart
